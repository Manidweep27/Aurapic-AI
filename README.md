# Aurapic-AI

AuraPic is a privacy-first, secure, AI-powered web platform that matches guests with their high-resolution photographs in real-time. By scanning a localized QR code at the event or wedding, uploading an enrolment selfie, and using secure face-matching algorithms, guests instantly view and download their uncompressed photos securely.

## 🚀 Key Features

- **Instant Face Recognition**: Rapidly tags and matches guests with their photos from events.
- **Guest Portal**: Localized QR-code check-in, live selfie capture, and a private personalized photo gallery.
- **Photographer Dashboard**: Bulk upload event albums, monitor matching analytics, manage active events, and export stats.
- **Aura AI Assistant**: Conversational assistant embedded to help guests find photos or answer questions.
- **Modern Glassmorphic UI**: Fast, responsive React + Vite interface with smooth micro-animations and dark-mode aesthetics.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Vanilla CSS with modern responsive design system
- **Icons & Assets**: Scalable SVGs, custom components

## 📦 Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/Manidweep27/Aurapic-AI.git
cd Aurapic-AI
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```

The app will be accessible at `http://localhost:5173`.
